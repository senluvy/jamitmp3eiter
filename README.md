# MP3 플레이리스트 메이커

실제 MP3 음원을 넣거나 재생하는 서비스가 아니라, 레퍼런스 이미지와 같은 레트로 MP3 플레이어 화면을 **텍스트 + 이미지로 디자인**하는 GitHub Pages용 편집기입니다.

## 주요 기능

- 가로 / 세로 버전 전환
- 가로: 앨범 커버 + 플레이리스트 제목 + 노래 제목 + 가수 + 재생바
- 세로: 플레이리스트 제목 + 노래 제목
- LCD 내부에는 뒤로가기/확인/이전/다음 같은 별도 컨트롤러를 넣지 않음
- 원형 컨트롤러는 기기 하단에만 표시
- 노래마다 제목과 보조 텍스트(가수)를 직접 입력
- 실제 MP3 파일 업로드 기능 없음
- 앨범 커버는 사각 영역 클릭으로 이미지 파일 선택
- 메인 색상 기본값 #3E76CB
- 파란색 → 하늘색 그라데이션 바디
- HTML 내보내기
- PNG 저장
- GitHub Pages에서 바로 실행 가능

## 배포

`index.html`, `style.css`, `script.js`를 GitHub 저장소 루트에 업로드한 뒤 `Settings → Pages → Deploy from a branch → main / root`를 선택하세요.

PNG 저장에는 html2canvas CDN을 사용합니다. 인터넷 연결이 없는 환경에서는 PNG 버튼이 작동하지 않을 수 있습니다.
